# 1Padel.App

Прототип приложения 1-Padel для игроков и организаторов: Expo / React Native, iOS, Android и веб.

## Текущий статус
Публичное расписание подключено к https://1-padel.com/api/public/tournaments. Фильтры: пол, уровень, формат, участие. Организаторский экран пока локальная демонстрация.

Клиент входа и «Мои мероприятия» подготовлен, но пока использует первоначальный контракт /api/mobile-auth и /api/mobile/me. Сервер в upstream padel-core-service реализован независимо (PR #639), поэтому перед проверкой настоящего входа нужна адаптация к опубликованным /api/auth/* и /api/players/me/tournaments. Google на текущем сервере возвращает в /app/ на сайте. Нельзя считать Google или вход в существующий аккаунт уже проверенными.

Отдельное веб-размещение требует разрешённого адреса клиента на сервере и согласованного возврата Google. Через native HTTPS-запросы CORS браузера не применяется. Пароли, Google secret и пользовательская база в этот репозиторий не включены.

## Запуск
Node.js и pnpm. Установить зависимости: pnpm install --frozen-lockfile. Запуск: pnpm start или pnpm web. Проверки: pnpm test и pnpm typecheck.

## Веб-сборка
pnpm exec expo export --platform web --output-dir dist

Для размещения в подпапке: PADEL_WEB_BASE_PATH=/app pnpm exec expo export --platform web --output-dir dist. Политика сервера должна разрешать адрес опубликованного приложения. scripts/build-site.mjs из прежнего серверного пакета рассчитан на monorepo mobile-app/ и не используется в этом отдельном репозитории.

## Структура
App.js — оболочка; src/ — расписание, фильтры, вход, личные записи, переводы и локальный подсчёт результатов; assets/ — изображения; tests/ — контрактные и доменные проверки; metro.config.cjs — только публичный GET proxy для локального веб-просмотра.
